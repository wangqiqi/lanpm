## 二、微信借鉴.md 全文快照（2026-05-29）

> **用途**：记录微信桌面版群聊界面中**值得借鉴的交互与信息结构**，并明确 **LanPM 不必照搬** 的部分。  
> **背景**：LanPM 是项目协作桌面客户端（Apple HIG + Ant Design），不是纯 IM。

### 2.1 产品差异（为何不能照抄微信）

| 维度 | 微信 | LanPM |
|------|------|-------|
| **群 / 会话数量** | 用户常有几十～上百个聊天 | 每人参与的项目群**数量有限**（通常个位数～十数个） |
| **群的语义** | 社交群、工作群、公众号等混合 | **一个群 = 一个项目**（或职能群 / 匿名群） |
| **核心任务** | 以聊天为主 | 聊天 + 看板 + 任务树 + 甘特 + 文件 |
| **导航重心** | 左侧会话列表是主入口 | **TopBar 切项目** + **BottomNav 切视图** |
| **侧栏角色** | 无独立「成员列表」栏 | 聊天页左侧固定 **成员列表**（协作场景更重要） |

**结论**：微信的 **三栏 IM 骨架**对 LanPM **优先级低**；应优先借鉴 **单会话内的聊天体验** 和 **少量通用 IM 习惯**，而不是复制「多会话管理中心」。

### 2.2 三栏结构对照

```
微信 PC 典型布局
┌──────┬──────────────┬────────────────────────────┐
│ 图标 │  会话列表     │  当前聊天（群名/消息/输入）   │
│ 栏   │  搜索+预览+时间│                            │
└──────┴──────────────┴────────────────────────────┘

LanPM 现有布局（docs/01 §6.1、docs/04 §6.1）
┌─ TopBar：项目下拉 / 搜索 / 设置 ─────────────────┐
├─ 聊天视图 ────────────────────────────────────────┤
│ ┌ 成员列表 240px ┐ ┌ 消息区 + Composer ─────────┐ │
│ │ 在线状态 / @   │ │ 群聊|私聊 Segmented         │ │
│ └────────────────┘ └────────────────────────────┘ │
└─ BottomNav：聊天 / 看板 / 树 / 甘特 / 文件 ───────┘
```

| 微信区域 | LanPM 对应 | 是否借鉴 |
|----------|------------|----------|
| 最左图标栏 | `BottomNav` + `TopBar` | ❌ 不复制 |
| 中间会话列表 | `TopBar` 项目下拉；私聊见 `DmSessionBar` | ⚠️ 弱借鉴 |
| 右侧聊天主区 | `ChatView` 消息 + Composer | ✅ 主要借鉴区 |
| （无）成员侧栏 | `MemberList` | ✅ LanPM 独有优势，保留 |

| 纯社交型群设置 | LanPM 走项目/局域网发现 |

**从微信借「聊天手感」和「IM 微习惯」，不借「多会话管理中心」和「微信视觉」；LanPM 的群是项目，导航重心在 TopBar + 协作五视图，成员侧栏才是差异化。**
