# 归档目录

> 历史报告与已完成清单。**`docs/`、`.cursor/` 不引用本目录**；现行规范见 `docs/`，待办见根目录 `todo.md`。

## 目录

| 子目录 | 内容 |
|--------|------|
| `audit/visual/` | 视觉一致性全量审计 |
| `audit/docs-code/` | 文档↔代码差异（`verify:docs-code` 刷新 §1） |
| `todo/` | 已完成 todo 迁出（**根目录 `todo.md` 仅保留未勾项**） |
| `review/` | V-14b 审图、UI/UX 评估与检查报告 |
| `milestone/` | M3/M7 等里程碑实现说明 |
| `plan/` | plan 迁出 |
| `docs-meta/` | 文档体系合并、原型迁移记录 |
| `prototypes/` | 历史 HTML 原型 |

## 命名

`YYYYMMDD_HHMMSS_功能_模块说明.md`（示例：`20260529_165655_视觉一致性校验_rc35.md`）
