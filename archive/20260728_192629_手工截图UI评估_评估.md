### 3.1 聊天（18-01-06）

**亮点**

- 成员侧栏 + 气泡 + 任务/文件引用卡片层次清楚；己方浅蓝气泡符合 §1 约定。

**问题**

| 级别 | 问题 | 建议 |
|------|------|------|
| P1 | **聊天上下文条**「打开看板 / 群文件」与底栏 **看板、文件** Tab 功能重复，占垂直空间 | 收敛为「在线人数」单行，或改为可折叠；快捷入口仅保留底栏未覆盖的（如驾驶舱） |

## 4. 横切问题

### 4.1 底栏选中态 vs 文档（P1）

`docs/04` §1.6 写明底栏 Tab 选中：**仅 accent 着色，无竖线/顶条/底色块**。

当前实现 `BottomNav.module.css` 的 `.tabActive` 使用了 `background: var(--lanpm-selected-bg)`，截图中 **聊天 / 看板 / 任务树 / 甘特 / 日历 / 白板** 均可见浅蓝底块，**与 SSOT 冲突**。

```85:89:src/renderer/src/layout/BottomNav.module.css
.tabActive {
  color: var(--lanpm-accent);
  font-weight: 600;
  background: var(--lanpm-selected-bg);
}
```

**建议**：去掉 `.tabActive` 背景，保留字重 + 图标 scale；若需反馈，仅用 accent 色与轻 scale（§1 iOS Tab Bar 微反馈）。

## 6. 建议执行顺序

1. **立刻可验**：重启 `npm run dev` → 触发逾期通知 → 确认 toast 标题为 **LanPM** 且图标正确。
2. **小改快赢**（≤5 项，可直接 `/run`）：UX-S-01、UX-S-02、UX-S-05。
3. **打包门禁**：TASK-003 打 x64 包 → 对比七页边框/token + 任务栏 exe 图标 → `verify:electron-smoke`。
4. **补拍**：暗色八视图 + 含任务栏的全屏截图写入 `docs/screenshots/baselines/dark/`（whiteboard 待 SPRINT-13）。
5. **归档**：本轮评估定稿后可复制到 `archive/YYYYMMDD_HHMMSS_手工截图UI评估_评估.md`（按仓库归档命名）。

## 7. 结论

九张手工截图证明 **LanPM 1.33.4 dev 主流程 UI 已达可演示质量**，信息架构与驾驶舱层级符合产品文档。当前主要风险不在「能不能用」，而在 **规范细节（底栏选中态、聊天冗余条）、甘特/日历高密度可读性、以及打包层品牌与 CSS token**。建议优先处理 P1 四项 UX + 打包复验后，再进入 SPRINT-03 收尾归档。
