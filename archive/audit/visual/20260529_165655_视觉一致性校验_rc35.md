## 2. 设计体系（SSOT）

### 2.1 视觉定位

- **风格**：Apple HIG 取向（系统字体、毛玻璃顶/底栏、低饱和分隔线）
- **组件库**：Ant Design 5 + 自研区域交互组件
- **双通道主题**：
  - CSS：`html[data-theme='light'|'dark']` → `global.module.css`
  - Ant：`ThemeProvider.tsx` 中 `LANPM_PALETTE` 实色同步（Ant 无法对 CSS 变量做颜色运算）

### 2.2 核心令牌一览

| 变量 | 亮色 | 暗色 | 用途 |
|------|------|------|------|
| `--lanpm-bg` | `#f5f5f7` | `#000000` | 页面底 |
| `--lanpm-accent` | `#0071e3` | `#0a84ff` | 强调、焦点环、选中文字 |
| `--lanpm-text` | `#1d1d1f` | `#f5f5f7` | 正文 |
| `--lanpm-text-secondary` | `#86868b` | `#98989d` | 次要文案 |
| `--lanpm-border` | `rgba(60,60,67,.12)` | `rgba(84,84,88,.36)` | 面板边框 |
| `--lanpm-hover-bg` | 浅灰透明 | 浅白透明 | 区域 hover |
| `--lanpm-accent-fill` | 蓝 8% | 蓝 12% | 选中底 |
| `--lanpm-nav-bg` + `--lanpm-blur` | 半透明白 + blur | 半透明黑 + blur | TopBar / BottomNav |

完整列表见 `src/renderer/src/styles/global.module.css`。

### 2.3 Ant Design 与 CSS 圆角对照

| 来源 | 圆角 |
|------|------|
| `ThemeProvider` `borderRadius` | **10**（按钮、输入等 Ant 控件） |
| `borderRadiusLG` | **12** |
| 文档 §1 卡片/模块 | **8px**（`docs/04`） |
| 业务 `*.module.css` 卡片 | 多为 **8px** |
| `RegionButton` icon/pill | **10px** |
| `SetupWizard` 主卡片 | **14px** / 内区 **12px** |

**结论**：Ant 全局 10px 与业务卡片 8px 并存，属「控件 vs 内容卡片」分层，但文档未显式区分，新模块易误用 10px 做面板。

| `TopBar.module.css` | `#52c41a` / `#ff4d4f` / `#faad14` | 网络在线/离线/Stub | 中：与 Apple 系统色不一致，属 Ant 语义色 |

| `main.tsx` 启动失败 | `#fff`, `#ddd` | 预 React 错误 | 高：暗色用户刺眼 |
| `ganttExport.ts` | 导出 fallback `#ffffff` | PNG 导出 | 低 |
| `setup/avatar.ts` | 多色 PALETTE + `#fff` 字 | 默认头像 | 低（装饰） |

### 6.3 CSS 变量 fallback 问题

多处写法：`var(--lanpm-text-secondary, rgba(0, 0, 0, 0.45))`。

- **亮色**：fallback 可接受  
- **暗色**：若变量未加载，fallback 仍为「浅底深字」逻辑，**与暗色语义相反**  
- **现状**：`ThemeProvider` 会设置 `data-theme`，正常运行时走主值，风险主要在启动极早期

**建议**：fallback 改为与亮色一致的 hex（如 `#86868b`），或去掉 fallback 强制依赖令牌。

### 6.4 阴影硬编码

`chat.module.css`、`board.module.css`、`SetupWizard.module.css` 使用 `box-shadow: 0 4px 12px rgba(0,0,0,…)`，未复用 `--lanpm-shadow`。暗色下阴影深度不统一。
