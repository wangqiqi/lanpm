## 1. 评估框架

每条操作路径按以下维度审查：

| 维度 | 含义 |
|------|------|
| **入口** | 用户从哪开始该目标 |
| **步骤** | 最少点击/输入次数 |
| **反馈** | 成功/失败是否有可感知结果（toast、列表更新、Modal 关闭） |
| **出口** | 完成后用户落在哪、能否继续下一任务 |
| **闭环** | ✅ 完整 · ⚠️ 部分（缺反馈或多绕路） · ❌ 断环（失败丢数据或目标未达成） |
| **最短路径** | 当前实现是否等于理论最少步数；若否，说明冗余 |

## 2. 全局导航模型

```mermaid
flowchart TB
  subgraph boot [启动]
    A[App 启动] --> B{hydrated?}
    B -->|否| Spin[全屏 Loading]
    B -->|是| C{configured?}
    C -->|否| Setup[SetupWizard]
    C -->|是| Router[AppRouter]
  end

  subgraph shell [主壳层 MainLayout]
    Router --> TB[TopBar]
    Router --> Main[Outlet]
    Router --> BN[BottomNav 条件显示]
  end

  Main --> Cockpit["/cockpit 无 BottomNav"]
  Main --> Group["/g/:id/:view 有 BottomNav"]

  Group --> Chat[chat]
  Group --> Board[board]
  Group --> Tree[tree]
  Group --> Gantt[gantt]
  Group --> Files[files]
```

**BottomNav 显示规则**：路径匹配 `/g/:id/*` 时显示；驾驶舱 `/cockpit` **不显示**。

**群类型 → Tab 能力**（`tabRules.ts`）：

| 群类型 | 可用 Tab | 默认 Tab |
|--------|----------|----------|
| project | 全部 5 个 | chat |
| function | chat, files | chat |
| anonymous | chat | chat |
| dm:* | chat | chat |

## 3. 操作路径总表（闭环 + 步数）

图例：**步数** = 已处于正确群/视图时的最少操作数；**闭环** = 成功路径是否可感知完成。

### 3.1 启动与身份

| 目标 | 入口 | 步数 | 闭环 | 最短? | 说明 |
|------|------|------|------|-------|------|
| 首次完成身份配置 | App 自动 | 填表 1 + 提交 1 | ✅ | 是 | `SetupWizard` → toast → 进主界面 |
| 再次打开（已配置） | App 自动 | 0 | ✅ | 是 | `getSetupStatus` → 直接 `AppRouter` |
| 身份 API 失败 | App 自动 | — | ❌ | — | `App.tsx` catch 仅 `setHydrated(true)`，与「未配置」混淆，可能误进 Setup 或空身份主界面 |
| 启动后进默认群 | Setup 完成 / `/` | 0 | ⚠️ | 否 | 硬编码 `#/g/demo-project/chat`，群不存在则标题 fallback 为 ID |

### 3.2 群组与导航

| 目标 | 入口 | 步数 | 闭环 | 最短? | 说明 |

| 创建群 | TopBar「创建群组」 | 填表 + 确认 2 | ⚠️ | 是 | 成功跳转；**失败无 toast**（`CreateGroupModal` 无 catch） |
| 五视图切换 | BottomNav | 1 | ✅ | 是 | 禁用 Tab 有 Tooltip |
| 看板 ↔ 树 | 各视图 toolbar 链接 | 1 | ✅ | 是 | 互链闭环 |
| 进驾驶舱 | TopBar「驾驶舱」 | 1 | ✅ | 是 | 进入 `/cockpit` |
| 离开驾驶舱回群 | TopBar Select / Logo | 1–2 | ⚠️ | 否 | **无「返回上次群」**；Logo 回 `activeGroupId/chat`，多一步认知 |

## 4. 闭环状态汇总

### 4.1 ✅ 已闭环（主要 happy path）

- Setup 提交 → 主界面  
- BottomNav 五 Tab 切换（允许范围内）  
- 看板：创建 / 拖拽 / OTHER 原因 / 删除  
- 树：根/子任务创建、叶子改进度  
- 甘特：改期、依赖、导出  
- 文件：上传、书签 CRUD、导入导出  
- DM：发起 → 会话 → 返回群聊  
- 聊天：task_ref 跳转看板、/task 带标题、任务 Modal 创建  
- 主题 / 语言切换

## 6. 关键路径时序（断环示意）

### 6.1 发送文本（断环）

```mermaid
sequenceDiagram
  participant U as 用户
  participant CV as ChatView
  participant CS as chatStore
  participant API as IPC

  U->>CV: 点击发送
  CV->>CV: setDraft('')  %% 先清空
  CV->>CS: sendText(text)
  CS->>API: chat.sendText
  API--xCS: 失败
  Note over U,CV: 无 toast，draft 已丢 — 断环
```

**修复**：`await sendText` 成功后再清 draft；catch 中 `message.error` + 恢复 draft。

### 6.2 全局搜索（断环）

```mermaid
sequenceDiagram
  participant U as 用户
  participant GS as GlobalSearch
  participant R as Router
  participant V as Chat/Board

  U->>GS: 选择搜索结果
  GS->>R: navigate(path, { state: highlight*Id })
  R->>V: 渲染视图
  Note over V: 不读取 location.state
  U->>V: 手动查找 — 断环
```

**修复**：目标视图 `useEffect` 读 state → `scrollIntoView` + 3s 高亮动画。

### 6.3 DM 与 TopBar 不同步

```mermaid
flowchart LR
  A[用户在 dm:alice/chat] --> B[MainLayout setActiveGroupId dm:alice]
  B --> C[TopBar Select value=dm:alice]
  C --> D[options 仅 API 群列表]
  D --> E[Select 无匹配项 — 上下文断裂]
```

**修复**：Select 增加「私聊：{name}」option，或 DM 时用只读 Badge 替代 Select。

## 10. 结论

| 维度 | 结论 |
|------|------|
| **主流程闭环** | Setup、Tab 切换、看板/树/甘特/文件核心 CRUD、DM 往返 — **主 happy path 基本闭环** |
| **断环** | 搜索定位、发送失败、驾驶舱/启动错误、DM+TopBar 同步 — **8 处明确断环** |
| **最短路径** | 群内操作多数已最优；**驾驶舱往返、搜索定位、Setup 默认群** 存在可量化冗余 |
