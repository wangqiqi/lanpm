## 3. 技术架构：文档声明 vs 代码事实

### 3.1 已在 `docs/08` / `todo.md` 记录、但 PRD/README 仍写「已选型」

| 能力 | 文档出处 | 实现情况 | 说明 |
|------|----------|----------|------|
| 任务 **Yjs / CRDT** 同步 | `01` §1.3、`02` §13.3、`04` §10、`README` | ❌ 无 `yjs` 依赖；任务仅 **本机 SQLite** | `todo.md` B-01；`docs/08` 已知限制 |
| **WebRTC** DataChannel | `01` §1.3、`02` §13.1、`01` §10.4 | ❌ 无 `webrtc` 相关依赖；真网为 **TCP + ECDH + AES-256-GCM** | `docs/08`：LAN TCP 替代 DataChannel |
| **IndexedDB** 热缓存 | `01` §1.3、`04` §5、`README` | ❌ 仓库内无 `indexedDB` 使用 | 仅 SQLite（`better-sqlite3`） |
| **远端文件 P2P 下载** | `03` §16.7、`todo` v1.1 | ⚠️ UI/元数据为主，完整远端拉取未闭环 | `docs/08` post-RC |
| **7 天离线补同步** | `03` §16.11（P0 表述） | ❌ 无队列实现 | `docs/08` post-RC；与 P0 文案冲突 |
| **群组密钥 24h 轮换** | `02` §13.5 | ⚠️ 协议类型含 `group_key_rotate`，**主进程无处理逻辑** | 仅类型/文档 |
| **HMAC-SHA256** 报文认证 | `02` §13.4 表 | ⚠️ 使用 **AES-GCM authTag**，非独立 HMAC 字段 | 安全强度相当，与文档字段描述不一致 |
| **UDP 组播发现** | `02` §13.2 | ❌ 仅 **UDP 广播**（端口 `43123` 已实现） | 跨子网组播未做 |
| **手动添加节点**（IP:端口） | `02` §13.2 | ❌ 未发现 UI/IPC | VPN 场景待补 |

### 3.2 部分实现、与文档细节不符

| 能力 | 文档 | 实现 |
|------|------|------|
| 传输加密 | DH 2048 + AES-GCM + HMAC | ✅ ECDH（`secp256k1`）+ AES-256-GCM；❌ 独立 HMAC |
| 文件分片 / 队列 ≤3 | `01` §10.4、`02` §13.5 | ✅ `FILE_CHUNK_SIZE` 256KB、`FILE_MAX_CONCURRENT`；`FilesView` 展示队列 |
| **断点续传** | `01` §10.4、`03` §16.7 **P0** | ⚠️ 有分片上传与 `transferred_bytes` 字段，**无中断后续传逻辑**（`file` 模块无 resume） |
| SQLite **库级加密** | `plan.md` §3.2「可加密」 | ❌ 仅 AI API Key 等字段加密（`safeStorage` / dev fallback） |
| 网络模式 | `plan` §9.1：`LANPM_NETWORK=stub\|real` | ✅ `src/main/network/index.ts` |

## 8. 不一致性分级汇总

### P0 — 影响对外承诺或发布判断

1. **README / docs/08 / plan 表** 的 RC 版本号未统一到 rc.4。  
2. **PRD/README** 仍将 Yjs、WebRTC、IndexedDB 写成现行栈，易误导集成方。  
3. **`03` §16.11** 7 天离线同步标 P0 但未实现且无排期单号。  
4. **发布门禁**（三平台、性能手测、双机）未满足即不宜标 `1.0.0`。

### P1 — 功能体验 / PRD 细节

1. 任务详情侧栏、聊天发文件、书签 WebView、视频预览。  
2. 搜索跳转高亮未接线。  
3. 断点续传、传输限速与历史。  
4. 驾驶舱部门视图、个人信息面板。  
5. i18n 与 `docs/05` 双语约定未收尾。

### P2 — 文档维护 / 架构演进项

1. 组播发现、手动加节点、群组密钥轮换、HMAC 字段与实现对齐说明。  
2. `plan.md` 尾部乱码行修复。  
3. 列内 Sortable（`todo` B-03）、任务 Yjs、远端文件（v1.1 backlog）。

## 10. 评估结论（供决策）

- **开发里程碑（M0–M7）**：与归档计划、`CHANGELOG`、`verify:m7` **一致**，可认为工程阶段目标已达成。  
- **产品需求文档（PRD）全文**：约 **70%～80% P0 交互已可见**，分布式协同、部分文件/聊天/驾驶舱细节、离线策略等与 PRD **不一致**；其中约一半属 **已知情 post-RC**，另一半属 **PRD 未降级或 UI 未实现**。  
- **正式版 1.0.0**：按 `plan.md` §10 与 `todo.md` RC 节，**尚未达到**文档定义的发布门禁。
