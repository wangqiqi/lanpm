## 5.1 M0：初始化与身份配置

- 任务清单：
  - 初始化 `src/main` / `src/preload` / `src/renderer` 分层结构（React 18 + TypeScript）。
  - 实现首次配置向导：用户名、设备名、部门、头像。
  - 实现用户名冲突后缀规则：自动 `-yymm` + 手动修改校验。
  - 持久化本地身份档案（userId、displayName、devices）。
  - 实现 **NetworkStub**：内存/本机回环通道，模拟节点发现与消息投递（接口与 `docs/04` SyncEnvelope 对齐）。
- 交付物：
  - 向导页面 + 本地配置存储 + 启动跳转流程 + NetworkStub 模块。
- 验收点：
  - 重启后可恢复身份，重复用户名能自动分配后缀。
  - 同一机器可启动两个实例，通过 Stub 互相发现并收发测试消息。

## 5.7 M6：网络层与加密闭环（✅ v0.10.0-m6）

- 任务清单：
  - UDP 广播发现（43123）、心跳 5s、离线 15s。
  - LAN TCP 可靠数据通道 + 指数退避重连（1s→20s）。
  - ECDH + AES-256-GCM 加密收发。
  - `initNetwork` 工厂：`LANPM_NETWORK=stub|real`（默认 real，Stub 保留）。
  - 同用户多设备在线聚合（presence + 心跳）。
- 交付物：
  - `network/real/` + `crypto/` + `verify:m6`。
- 验收点：
  - `npm run verify:m6`；双机手验见 `docs/06` §4（`LANPM_TCP_PORT` 区分端口）。
