# 暗色主题截图基线

由无头 Electron 生成，**非**设计稿定稿。全目录说明见 [`../README.md`](../README.md)。

## 生成命令

```bash
npm run build && npm run verify:visual-screenshots
```

默认输出 `.lanpm/visual-screenshots/`（gitignore）。将 `dark_*.png` 复制到本目录入库。

| 文件 | 视图 |
|------|------|
| `dark_chat.png` | 聊天 |
| `dark_board.png` | 看板 |
| `dark_tree.png` | 任务树 |
| `dark_gantt.png` | 甘特图 |
| `dark_calendar.png` | 日历 |
| `dark_whiteboard.png` | 白板（SPRINT-13 补全） |
| `dark_files.png` | 文件 |
| `dark_cockpit.png` | 驾驶舱 |
