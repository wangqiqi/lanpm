## 16. 验收标准

### 16.1 首次配置

- 首次启动弹出配置向导
- 必须填写用户名和设备名
- 用户名重复时自动添加 `-yymm` 后缀
- 允许用户手动修改后缀
- 配置后生成唯一 ID 并保存

### 16.2 主界面

- 顶部栏包含：项目下拉、驾驶舱、搜索、主题切换、语言切换、个人信息
- 底部包含 5 个导航：聊天、看板、任务树、甘特图、文件
- 支持亮色/暗色主题切换
- 全局搜索至少支持按关键字过滤**任务**与**消息**（P0）

### 16.3 聊天

- 左侧显示成员列表（含在线状态：在线/离开/离线）
- 支持发送文本消息
- 支持发送代码块 + 语法高亮
- 支持 @提及
- 支持私聊（P0）
- 支持 `/task` 快捷创建任务（P0）
- 消息已读回执显示（同用户任一设备已读即已读）
- @提及 时触发桌面通知
- M2 阶段：基于 NetworkStub 双实例完成消息与回执闭环；M6 阶段：真实局域网双机复验

### 16.4 看板

- 包含 4 列：TODO、IN PROGRESS、DONE、OTHER（存储值：`todo`/`doing`/`done`/`other`）
- 支持拖拽卡片跨列移动（`@dnd-kit/core`，见 `docs/05` §8）
- 支持新增/编辑/删除任务
- **M3 实现证据**：`BoardView` + `npm run verify:m3`；手验步骤 [06 §2](./06_测试与联调手册.md)；说明 [07](./07_M3_看板与任务树实现说明.md)
- **当前限制**：看板仅根任务；任务未 P2P 同步（本机 SQLite）

### 16.5 任务树

- 支持树形展示父子任务
- 支持展开/折叠
- 父任务自动汇总子任务进度（`applyAggregatedProgress`，读时计算）
- 全局搜索结果可在树中高亮（P0，与 01 §8.2 一致）
- **M3 实现证据**：`TaskTreeView`；与看板同源 `taskStore`；见 [07](./07_M3_看板与任务树实现说明.md) §4.2

### 16.6 甘特图

- 显示任务时间轴
- 支持拖拽调整任务起止时间
- 支持日/周/月视图切换
- 支持任务依赖关系 FS/SS/FF/SF 与里程碑标识（P0）
- 导出 PNG/PDF（P1）

### 16.7 文件

- 显示文件列表
- 支持 Office 文件预览（LibreOffice 本地转换，不出域）
- 支持网址添加 + 内嵌 WebView 访问
- 支持文件上传/下载（P2P；M6 真实链路，M4 可用 Stub 验证 UI）
- 支持断点续传与传输队列（并发 ≤3）（P0）
- 书签从浏览器导入/导出（P1）

### 16.8 群组

- 支持创建项目群组
- 支持创建职能群组
- 支持创建匿名群组（成员匿名）
- 项目/职能群组：业务数据（任务/文件等）在群内全员同步
- 匿名群组：仅实时文本；无文件 Tab、无历史同步（退出再进无历史，见 `01` §11.3）

### 16.9 驾驶舱

- 显示所有项目列表和进度
- 支持配置 API-Key
- 支持**手动触发** AI 任务审核与进度评估（P0；仅脱敏字段外发）
- 支持生成周报/月报
- 自动化巡检与阻塞预警推送（P1）

### 16.10 分布式

- UDP 广播发现同网段节点
- P2P 消息传输加密
- 同用户多设备在线合并显示

### 16.11 非功能指标（P0）

- 冷启动时间 ≤ 3s（M7 统一测量，方法见 `docs/06` §2）
- 空闲内存 ≤ 200MB，聊天活跃 ≤ 350MB（M7 采样 3 次取中位数）
- 主界面交互响应 ≤ 100ms（切换底部 5 视图、发送消息，各测 10 次取 P95）
- 崩溃后可恢复上次会话
- **（P1 / post-RC）** 离线消息 7 天内可补同步（实现排期见 todo **ARCH-07** / **PRD-F-07**）

### 16.12 测试与联调（P0）

- M2：NetworkStub 双实例聊天 + 已读回执（见 `docs/06` §1）
- M6：局域网双机/多机发现、加密消息、文件 P2P（见 `docs/06` §3）
- M7：按 `docs/06` §2 完成性能与稳定性回归
