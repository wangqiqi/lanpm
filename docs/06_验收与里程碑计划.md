## 3. 验收标准（§16 条文）

### 16.1 首次配置

- 首次启动弹出配置向导；必须填写用户名和设备名
- 用户名重复时自动添加 `-yymm` 后缀；允许手动修改
- 配置后生成唯一 ID 并保存

### 16.2 主界面

- 顶栏：项目下拉、驾驶舱、搜索、主题、语言、个人信息
- 底部 5 导航：聊天、看板、任务树、甘特图、文件
- 亮色/暗色主题；全局搜索至少覆盖任务与消息（P0）

### 16.3 聊天

- 成员列表含在线/离开/离线；文本、代码块、@、私聊、`/task`
- 已读按 `userId` 聚合；@ 触发桌面通知
- M2：NetworkStub 双实例；M6：真网双机复验

### 16.4 看板

- 四列 `todo`/`doing`/`done`/`other`；`@dnd-kit/core` 跨列拖拽（`docs/04` §8）
- OTHER 须填原因；**M3**：`BoardView` + `verify:m3`；手验 [05](./05_测试与联调发布.md) §4

### 16.5 任务树

- 父子展开折叠；父进度为子任务均值；与看板同源 `taskStore`
- **M3**：`TaskTreeView`；见 [05](./05_测试与联调发布.md) §7

### 16.6–16.12

甘特、文件、群组、驾驶舱、分布式、非功能、联调条文与 **§1 P0 清单** 及 **§2.2 映射表** 一致；非功能指标：冷启动 ≤3s、空闲 ≤200MB、聊天 ≤350MB、交互 P95 ≤100ms。
