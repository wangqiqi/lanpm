# 05_交互与UI约定

> 面向 M1 主框架与后续模块 UI 实现。索引见 [00_文档导航.md](./00_文档导航.md)。

---

## 1. 布局骨架

```
┌─ 顶部栏 56px ─────────────────────────────────────────┐
├─ 主内容区（flex:1，各视图路由）───────────────────────┤
└─ 底部导航 64px（5 Tab，固定）───────────────────────┘
```

- 最小窗口：1280×720；推荐：1440×900。
- 主内容区内边距：16px；卡片圆角：8px；模块间距：12px。

---

## 2. 导航与路由

| 底部 Tab | 路由 | 说明 |
|----------|------|------|
| 聊天 | `/g/:groupId/chat` | 默认进入页 |
| 看板 | `/g/:groupId/board` | 仅项目群组可用 |
| 任务树 | `/g/:groupId/tree` | 仅项目群组 |
| 甘特图 | `/g/:groupId/gantt` | 仅项目群组 |
| 文件 | `/g/:groupId/files` | 项目群组；职能群可用 |

- 职能群组：隐藏看板/树/甘特 Tab 或置灰并提示「仅项目群组支持」。
- 匿名群组：仅保留聊天 Tab。

---

## 3. 主题与国际化

| 项 | 约定 |
|----|------|
| 主题 | 亮色 / 暗色，持久化 `localStorage.theme` |
| 默认 | 跟随系统，可手动覆盖 |
| 语言 | 中文 `zh-CN`、英文 `en-US`，资源文件 `locales/` |
| 代码块高亮 | 跟随当前主题（dark/light） |

---

## 4. 顶部栏组件

| 组件 | 行为 |
|------|------|
| Logo | 回到上次项目 + 聊天视图 |
| 项目下拉 | 切换群组；展示类型图标（项目/职能/匿名） |
| 驾驶舱 | 跳转 `/cockpit` |
| 全局搜索 | 下拉结果：任务、消息（P0）；成员（P1） |
| 主题 | 切换亮/暗 |
| 语言 | 下拉切换 |
| 头像 | 打开个人设置（设备名、部门、API Key 入口） |

---

## 5. 状态与反馈

| 场景 | UI 反馈 |
|------|---------|
| 发送消息中 | 消息旁 ⏳ |
| 已发送 / 已读 | ✅ / ✅✅（按 `userId` 聚合） |
| 成员在线 | 🟢 在线 / 🟡 离开 / ⚪ 离线 |
| 网络断开 | 顶部条「连接中断，正在重试…」 |
| 加载中 | 骨架屏或 Spinner，≤300ms 不显示 |
| 错误 | Toast 3s 自动消失 + 可点击查看详情 |

---

## 6. 关键模块 UI 要点

### 6.1 聊天

- 左栏成员列表宽度：240px，可折叠。
- 输入框支持：附件、代码块、`/task` 提示。
- 代码块：等宽字体，最大高度 360px，可展开。

### 6.2 看板

- 四列等宽滚动；列最小宽度 280px。
- 拖放：整卡半透明；非法列红色边框提示。
- 拖入 OTHER：弹窗必填原因。

### 6.3 任务树 / 甘特图

- 树：缩进 20px/层；父任务进度条与百分比同列展示。
- 甘特：日/周/月切换在工具栏；依赖线颜色 `#6b7280`。

### 6.4 文件

- 左栏分类筛选；右栏列表 + 预览区（分栏或抽屉）。
- Office：预览区显示「本地转换中…」；失败提示下载。

---

## 7. 无障碍与键盘（P1 可增强）

- P0：`Esc` 关闭弹窗；聊天 `Ctrl+Enter` 发送。
- 底部 Tab：`Alt+1`~`Alt+5` 切换（可选）。

---

## 8. 技术实现建议

- UI 库：Ant Design 或 MUI（二选一，M0 锁定）。
- 样式：CSS Modules 或 Tailwind（与组件库配套）。
- 图标：统一一套（如 Lucide），禁止混用多套图标库。
