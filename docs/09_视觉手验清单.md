# 09_视觉手验清单

---

## 1. 前置条件

- 构建：`npm run dev` 或生产包 `npm run build && npm run start`
- 已完成首次配置向导
- 至少一个**项目群**（含任务数据）用于看板/树/甘特/文件

---

## 2. 手验步骤

| # | 页面 | 路由 | 亮色 ☐ | 暗色 ☐ | 检查点 |
|---|------|------|--------|--------|--------|
| 1 | 首次配置 | 清空 user-data-dir 启动 | | | 分组列表、主按钮 `--lanpm-accent` |
| 2 | 聊天 | `/g/:id/chat` | | | 己方气泡、@提及、侧栏边框 |
| 3 | 看板 | `/g/:id/board` | | | 列边框、拖放高亮环、卡片底 |
| 4 | 任务树 | `/g/:id/tree` | | | 空状态文案可读、树面板边框 |
| 5 | 甘特 | `/g/:id/gantt` | | | 任务条颜色、今日列、暗色网格 |
| 6 | 文件 | `/g/:id/files` | | | 表格选中行、预览区边框 |
| 7 | 驾驶舱 | `/cockpit` | | | 标题与群组页同级、卡片间距 |

**操作**：顶栏切换主题 → 每页停留 10s → 确认无 Ant 默认蓝（`#1677ff`）残留。
