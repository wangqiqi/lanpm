# 07_跨平台发版矩阵

> 对应飞鸽 §5.5 · Sprint `SPRINT-PLATFORM-MATRIX`（TASK-264+）。  
> 版本与产物以 `package.json` / `CHANGELOG` / GitHub Release 为准。

---

## 1. 目标交付面

| OS | x64 | arm64 | 安装形态 |
|----|-----|-------|----------|
| Windows | ✅ CI | ⚠️ 交叉/自建（见 §3） | NSIS `.exe` |
| macOS | ✅ CI（`macos-13`） | ✅ CI（`macos-latest`） | `.dmg` |
| Linux | ✅ CI（`ubuntu-22.04`） | ✅ CI（`ubuntu-24.04-arm`） | AppImage · deb |
| 统信 / 麒麟 | 冒烟清单 §4 | 冒烟清单 §4 | 优先 deb / AppImage |

**不做（本 Sprint Out of scope）**：龙芯/申威等全 CPU 军备；强制信创真机进 CI。

---

## 2. TASK-264 审计 · 缺口表（实施前基线）

| 层 | 实施前现状 | 缺口 |
|----|------------|------|
| `electron-builder.yml` | win/mac/linux 有 target，**未显式 arch** | 依赖本机默认 arch，产物不可预期 |
| Release CI | Win x64 · mac arm64 · Linux x64 各一 | 缺 mac x64、Linux arm64；Win arm64 无 |
| npm scripts | 无 `dist:*` | 本地无法一键按平台/arch 打包 |
| native | 仅 rebuild `better-sqlite3` | `node-screenshots`（electron-screenshots）未纳入 ensure |
| 文档 | §5.5 一句「后续补齐」 | 无矩阵表 / 无信创冒烟清单 |

实施后以本文件 §1 + `verify:platform-matrix` 为准。

---

## 3. CI / 自建分工

| 产物 | 构建方式 |
|------|----------|
| Win x64 · mac x64/arm64 · Linux x64/arm64 | GitHub Actions `Release` workflow |
| Win arm64 | 文档保留：需 Windows ARM 自建机或交叉；**非**本矩阵强制 CI 绿 |
| 统信/麒麟 | 用人机冒烟 §4；deb 在同类 glibc 上优先验证 |

本地打包：

```bash
npm run dist:linux:x64
npm run dist:linux:arm64   # 建议在 arm64 主机或 CI 上跑
npm run dist:mac           # 需 macOS
npm run dist:win           # 需 Windows 或 wine（不推荐交叉）
```

原生模块：

```bash
npm run ensure:native      # better-sqlite3 + node-screenshots → Electron ABI
npm run rebuild:native     # --force
```

## 4. 统信 UOS / 银河麒麟 · 冒烟清单

在目标机安装 Release 产物后勾选：

- [ ] 安装成功（deb 或 AppImage 可执行）
- [ ] 冷启动进入首次配置 / 主界面
- [ ] 创建或加入项目群
- [ ] 发送一条文本消息
- [ ] 上传/下载一个小文件（&lt;10MB）
- [ ] 打开看板或白板任一视图无白屏

失败时记录：OS 版本 · CPU arch · 包文件名 · 日志路径（`~/.config/LanPM` 或等价）。
