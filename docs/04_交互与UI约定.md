## 1. 布局骨架

```
┌─ 顶部栏 56px ─────────────────────────────────────────┐
├─ 主内容区（flex:1，各视图路由）───────────────────────┤
└─ 底部导航 ~49px + safe-area（5 Tab，iOS 风格）────────┘
```

- 最小窗口：1280×720；推荐：1440×900。
- 主内容区内边距：**`var(--lanpm-canvas-inset)`**（等同 **`var(--lanpm-space-5)`** · 16px；`MainLayout.main` / `mainChat`）；模块间距：**`var(--lanpm-spacing-module)`**（默认 **12px**）。
- 顶栏高度：**56px**（`TopBar`）；底部导航：**49px** 内容区 + safe-area（`BottomNav`）。
- **顶底职责**：**顶栏** = 跨群切换、全局操作（发现/创建/搜索/网络）、偏好（主题/语言在用户菜单）；**底栏** = 当前群内七视图切换（聊天/看板/树/甘特/**日历**/**白板**/文件），不在顶栏重复 Tab。
- **顶栏降噪与一区一主操作**：品牌 Logo + **群切换** + **搜索** + 头像为主路径；驾驶舱 / 发现 / 建群 / 解散**始终平铺**为图标上文案（对齐底栏 Tab），窄屏仅压缩间距与字阶、**不**收入「更多」overflow。Logo 支持 hover 柔和缩放与偏转。
- **壳层气质（Excalidraw chrome，非画布手绘）**：顶/底栏 **通栏 + 岛感**（`--lanpm-shadow-island` + 毛玻璃）；选中/悬停用 **`--lanpm-selected-bg`**（蓝品牌淡底，非淡紫）；**亮色与暗色**共用同一套变量名。
- **iOS Tab Bar 微反馈**：选中时图标轻缩放与字体加粗，并带淡选中底；按压时（`:active`）微缩；过渡 `--lanpm-motion-fast`（无弹跳 keyframes）。
- **聊天己方气泡与卡片化**：己方气泡用浅底蓝字（`var(--lanpm-selected-bg)` + `color-mix` 描边：亮约 12% / 暗约 24%）；内部任务/附件引用（`task_ref`、`file`）卡片化，轻 hover 与发丝边框；**输入区**工具条 + 输入 + 发送同一岛面（`--lanpm-radius-lg` + `--lanpm-border`，focus `--lanpm-accent-ring`）。
- **空态 / 加载**：`ui/ViewState` 居中图标环 + 一行说明；底栏 Tab 仅 `--lanpm-motion-fast` 过渡（无弹跳 keyframes）。

### 1.2 间距尺度

与审查收敛的 magic number（8/10/12/14/16/48）对齐；定义于 `global.css` `:global(html)`，亮暗共用：

| Token | 默认 | 语义别名 | 典型场景 |
|-------|------|----------|----------|
| `--lanpm-space-1` | **8px** | `--lanpm-spacing-tight` | 紧凑 gap、列内卡片间距 |
| `--lanpm-space-2` | **10px** | — | 列头纵向、摘要区内边距 |
| `--lanpm-space-3` | **12px** | `--lanpm-spacing-module` · `--lanpm-spacing-panel` | **模块间距**、岛面板默认 gap |
| `--lanpm-space-4` | **14px** | `--lanpm-spacing-panel-y` | 面板标题区、卡片内边距 |
| `--lanpm-space-5` | **16px** | `--lanpm-spacing-panel-x` · `--lanpm-canvas-inset` | 面板水平内边距、主内容区 inset |
| `--lanpm-space-6` | **48px** | — | Setup 大留白、空态垂直间距 |

新样式**优先** `var(--lanpm-space-*)` 或语义别名；禁止在 Cockpit/Board/Calendar 岛式面板新增裸 `padding: Npx` / `gap: Npx`（`verify:visual` SP-402）。

### 1.3 圆角尺度

与 `ThemeProvider`（Ant `borderRadius: 12` / `LG: 16` / `SM: 8`）及 `--lanpm-radius-*` 对齐：

| 层级 | Token | 圆角 | 典型场景 |
|------|-------|------|----------|
| **控件小** | `--lanpm-radius-sm` | **8px** | 小按钮、日历 FC 按钮、高亮框 |
| **面板 / 控件** | `--lanpm-radius-md` | **12px** | 气泡、卡片、Ant 默认、甘特容器 |
| **岛面 / 列** | `--lanpm-radius-lg` | **16px** | 看板列、聊天工作区、树面板、日历宿主（`--lanpm-shadow-island`） |
| **强调** | `--lanpm-radius-xl` | **20px** | 大模态 / 少用强调面 |

> 辅助值：2px 滚动条/指示条、4px @提及、药丸 `999px`、网络状态点 `50%`。

### 1.4 页标题语义

| 页面 | 标题文案 | 组件 |
|------|----------|------|
| 聊天 | **无**页级大标题；当前群名 / DM 名仅在 **TopBar 群切换器** | 不渲染 `ViewHeader`；模式条 / 在线人数在 `ChatView` |
| 看板 / 任务树 / 甘特 / 日历 / 白板 / 文件 | **无**页级大标题；模块名由 **底栏 Tab** 选中态表达 | 不渲染 `ViewHeader`（与聊天页一致，避免与底栏重复） |
| 驾驶舱 | 「驾驶舱」 | `ViewHeader` |

**驾驶舱（领导面）**：跨群路由 `/cockpit`；`mainCockpit` + `scrollBody` 单滚动（`overflow-x:clip`）；岛感列表卡片。**需关注**条（项目级）→ **领导摘要**（单一岛八指标，禁双岛）→ **手风琴**需关注任务 / 项目进度 / 部门完成率（默认摘要，展开详情；部门列表不抢主滚）→ 报表（底、默认折叠）；延期/风险强调色；周报为主 CTA，AI 评估 text 次要。亮暗共用 token。布局与指标 SSOT 见 [01](./01_产品需求文档.md) §12.1；`verify:visual` 守卫 CK-401～415（密度手风琴 CK-410～414）。

驾驶舱页标题使用 Ant Design `Title level={4}`（`ViewHeader`）。群级任务视图无页级大标题。TopBar 群切换器与 Logo / icon / user / 搜索框同字阶（`--lanpm-font-title` · 600，icon/user 为 body）与控件高度（**统一 32px**）；组间竖分隔线高 20px、`align-self: center`。

## 2. 导航与路由

| 底部 Tab | 路由 | 说明 |
|----------|------|------|
| 聊天 | `/g/:groupId/chat` | 默认进入页 |
| 看板 | `/g/:groupId/board` | 仅项目群组可用 |
| 任务树 | `/g/:groupId/tree` | 仅项目群组 |
| 甘特图 | `/g/:groupId/gantt` | 仅项目群组 |
| 日历 | `/g/:groupId/calendar` | 仅项目群组；FullCalendar；有日期/推断窗口；**拖拽/拉伸改期**；点击编辑 |
| 白板 | `/g/:groupId/whiteboard` | 仅项目群组；Excalidraw；一群一板；可从任务打开并关联；导出 PNG 到群文件 |
| 文件 | `/g/:groupId/files` | 项目群组；职能群可用 |

- 职能群组：看板/树/甘特/日历/白板 Tab **置灰 + 锁图标 + Tooltip**；聊天页顶部 **可关闭说明横幅**（`FUNCTION_GUIDE_STORAGE_KEY`）；点击禁用 Tab 仍可弹出说明。
- 匿名群组：BottomNav **仅渲染聊天 Tab**（不展示禁用占位）。
- 主视图切换：**仅 BottomNav**（不在任务页工具栏重复七 Tab）；跨视图捷径用 **`ViewCrossLink`**（看板↔树、甘特→看板等 pill）。
- 窄屏（`≤1100px`）：TopBar 发现/创建/解散/驾驶舱收入 **更多** 菜单；全局搜索改为 **图标 + Popover**。宽屏上述操作为图标+文字平铺，不经「更多」。
- 全局搜索：结果副标题含 **目标视图**（`search.openInView`）。
- 聊天上下文栏（项目群）：**看板**、**群文件** 快捷入口。

### Hash 路由与深链（`UX-V-08`）

Electron 渲染进程使用 **HashRouter**（URL 形如 `file:///…/index.html#/g/:groupId/chat`）。

| 场景 | 说明 |
|------|------|
| 应用内导航 | `navigate()` / `<Link>` 正常，无需额外处理 |
| 外部深链 | 可将完整 `index.html#…` 路径作为启动参数；首屏由 React Router 解析 hash |
| 刷新 / 重启 | hash 保留当前群与视图，适合桌面端单页应用 |
| 限制 | 无服务端 SSR；分享链接需包含 `#` 段；搜索引擎不索引 |

## 6. 关键模块 UI 要点

### 6.0 任务多视图：内容统一、交互分视图

**原则**：看板 / 任务树 / 甘特图**不必**交互一致（单击、双击、拖拽可以不同），但**内容必须统一**——同一条 `Task` 记录、同一套 `taskStore` + `task:*` IPC；任一视图保存后，其它视图刷新即看到相同字段值。

| 约定 | 说明 |
|------|------|
| 数据模型 | 以 `docs/04` 任务实体为准；禁止某视图单独维护「另一份任务表」 |
| 编辑契约 | 完整字段保存走 `TaskDetailSaveInput`（`TaskDetailPanel` / `TaskEditModal` 共用） |
| 展示范围 | 看板**平铺全部任务** + **关系可视化**（族色条/标签/悬停高亮）；树列**层级**；甘特列**排期与依赖连线**——呈现不同，底层仍是同一批 `taskId` |
| 视图重点 | 各视图只**突出**本场景字段；未在当页展示的字段仍存在于数据中，并可在跳转后的编辑入口修改 |

| 视图 | 交互重点（示例） | 内容重点（展示/编辑） |
|------|------------------|------------------------|
| 看板 | 拖列改状态、悬停高亮关联、FS 前置拦截 | 状态列、**独立 tags**（≠ 优先级；**仅可选群标签字典**，禁自由造词）、父子/同级/依赖标签、**族色条**（`taskFamily.module.css`） |
| 任务树 | 选中侧栏、行内改进度、详情**前置/后继** | 父子结构、**同色条**、跳转看板/甘特定位 |
| 甘特 | 拖条改期、单击改日期、双击里程碑；工具栏 **放大/缩小**；打开时 **今日居中**；日期头与水平滚动条固定（与垂直滚动解耦） | 起止时间、依赖、里程碑、**关联任务条同色** |
| 日历 | 月/周浏览、**拖拽/拉伸改期**（`updateSchedule`）、点击打开编辑 | 有日期用真实排期；**无日期与甘特相同默认窗口**（虚线；拖动后落库为实线）；`endDate`=到期；FullCalendar + interaction |
| 白板 | 手绘协作画布、自动保存、导出 PNG | Excalidraw；一群一板；任务「打开白板」写 `linkedTaskId`；导出进群文件（关联任务时顺带发聊） |

**日历 / 白板帮助（降噪）**

| 视图 | 约定 |
|------|------|
| 日历 | **无**常驻工具栏长文案；宿主右上角 **`?`** → Popover 展示 `calendar.toolbarHint`（拖拽改期 · 虚线推断窗口等） |
| 白板 | 首次进入 **toast**（`WHITEBOARD_GUIDE_STORAGE_KEY`）；Excalidraw 顶右浮动区 **`?`**；从任务打开时底角 **紧凑徽章**（`whiteboard.linkedHint`），不占顶栏 |

**工期健康度（三视图统一，不落库）**

| 项 | 约定 |
|----|------|
| 计算 | `shared/task/scheduleHealth.ts`：`getTaskScheduleHealth`、`getExpectedProgressPercent`；UI 类名与色值见 `scheduleHealthUi.ts` / `scheduleHealth.module.css` |
| 语义 | **绿** `on_track`：有排期且 `progressPercent` ≥ 期望进度；**深黄** `behind`：低于期望；**纯红** `overdue`：已过 `endDate`（延期优先）；`none`：无排期/未开始/已完成，不着色 |
| 排期输入 | 优先 `startDate`+`endDate`；仅 `endDate` 按单日；仅 `startDate` 默认 +7 天；无日期不标色 |
| 看板 | 整卡底纹 + 截止/进度字色（最强） |
| 任务树 | 行内左缘色条 + 进度条色；详情 `Alert` 展示期望/当前 % |
| 甘特 | 条样式：`scheduleHealth.ts` 内 `mergeGanttBarStyles` 合并族色（延期红条、落后黄/正常绿进度） |
| 驾驶舱 | `delayedCount` = 延期任务数；`riskProjectCount` = 风险项目数；项目排序 delayed→risk→normal；项目 `risk`/`delayed` 与看板 schedule 规则同源 |

甘特图日期弹窗仅编辑起止日期属**交互裁剪**；完整字段请在看板（双击卡片）或任务树（右侧详情）修改，或通过甘特弹窗内「在看板中打开」跳转。

### 6.1 聊天

- 左栏成员列表宽度：240px，可折叠。
- **层次（亮/暗）**：成员侧栏、群聊/私聊模式条、上下文栏、输入区铺底 `--lanpm-surface-solid`；消息区保持 `--lanpm-bg` 作沟底，分界用 `--lanpm-border`（亮色约 18% 透明度，见 `global.module.css`）。
- 群级任务视图无页级 `ViewHeader`；驾驶舱保留 `ViewHeader` 与顶栏操作区。
- 输入框支持：附件、代码块、`/task` 提示。
- 代码块：等宽字体，最大高度 360px，可展开。
- **Markdown 文本**：含 `**`、列表、围栏代码等语法，或 `meta.source: ai-assistant` 的转发消息，由 `ChatMessageText` + 共享 `MarkdownView` 渲染（`@` / `#任务` 高亮不变）。
- **`/task`（M3）**：`parseTaskCommand`；无标题时打开 `TaskCreateModal`；有标题时 `createFromChat` 并插入 `task_ref` 气泡（点击跳转看板）。仅项目群显示「任务」按钮（`taskAllowed`）。

### 6.2 看板

- 四列等宽滚动；列最小宽度 280px（`board.module.css`）。
- 拖放：`@dnd-kit/core`；整卡半透明（`opacity: 0.5`）；`DragOverlay` 浮层标题。
- 拖入 OTHER：`OtherReasonModal` 必填原因（与 `validateOtherReason` 一致）。
- **删除**：拖至看板底部**垃圾桶区**（`board.trashDrop`）或任务树/卡片内删除操作；与 [01](./01_产品需求文档.md) §7.3「右键或拖至垃圾桶」一致。
- 组件：`BoardView`、`KanbanCard`、`BoardDependencyLines`、`TaskEditModal`；路由 `/g/:groupId/board`；**全部任务**平铺；卡片 **独立标签**（`Task.tags`，与优先级 Tag 并存；编辑仅可选群标签字典，禁自由造词）；工具栏 **标签多选筛选（OR）** + **群级标签色字典**（`group_tag_meta` / `group_tag_patch` LWW；色板写 IPC，芯片优先字典色否则 `tagColorHash`；首次可从本机 localStorage 一次性导入）；描述框 **远端文本 caret**（`task_awareness.caret`，彩色竖线+显示名；详情面板与看板编辑弹窗）；**关系**：左侧色条（同族/同根）、卡片标签（父/子/同级、FS 等待、后继）、悬停或菜单「固定高亮」关联卡；**FS 依赖连线**（SVG 叠加层，与甘特同源）：默认仅**悬停/固定高亮**时绘制（黄=前置、强调色=后继）；工具栏 **「显示全部 FS 连线」** 开关（默认关，`localStorage` 记忆）开启后绘制全板浅灰 FS 边，焦点相关边仍加强；逻辑见 `shared/task/boardRelations.ts`（`listFocusDependencyEdges` · `listAllDependencyEdges`）。
- 实现细节：[05_测试与联调发布.md](./05_测试与联调发布.md) §7。

### 6.3 任务树 / 甘特图

- 树：Ant Design `Tree`（`TaskTreeView`）；父任务行内 `Progress` 百分比（聚合值，见 04 §3.4）；支持展开/折叠、根/子任务创建、叶子进度编辑。
- 路由 `/g/:groupId/tree`；与看板共用 `taskStore` / `task:*` IPC。
- 甘特：**M4** 基于 **`gantt-task-react`** 封装；日/周/月切换在工具栏；依赖线颜色 `#6b7280`；排期字段与 `docs/03` 同源；`locale` 跟随应用语言（见 [05](./05_测试与联调发布.md) §7）。

### 6.4 文件

- **布局**：顶栏分类筛选（`ViewToolbar` start）+ 主操作（end）；其下搜索行；再下为**传输面板**（限速 + 队列/历史）；主体宽屏为左列表 + 右预览；**≤960** 仅列表，选中后底部 Drawer 展示同一预览树（关闭 Drawer 不强制清选中）。
- **工具栏层级**：
  - 主 CTA：**上传**（`type="primary"`）
  - 次要：添加书签
  - 折叠：「更多」下拉 — 书签导入 / 导出（不与上传抢同一视觉权重）
  - **限速不在顶栏**，放在传输面板顶部（与队列/历史同区）
- **空态**：无内容 / 搜索无结果 / 分类无匹配 — 文案区分，并提供「上传」「添加书签」引导按钮
- **书签预览主次**：标题 → 可复制 URL → 主按钮「系统浏览器打开」→ 次「发到群聊」→ 内嵌 WebView 降级为参考预览（附提示文案，高度受限）
- **列表行级区分（「全部」混排）**：书签行名称旁链接图标 +「书签」Tag + 浅底 `rowBookmark`；类型列短文案「链接」；预览列书签显示「—」（不堆「链接」噪音）；操作列书签仅外开图标。**不分表 / 不双 Tab**
- Office：预览区显示「本地转换中…」；失败提示下载。
