## 1. 布局骨架

```
┌─ 顶部栏 56px ─────────────────────────────────────────┐
├─ 主内容区（flex:1，各视图路由）───────────────────────┤
└─ 底部导航 64px（5 Tab，固定）───────────────────────┘
```

- 最小窗口：1280×720；推荐：1440×900。
- 主内容区内边距：**16px**（`MainLayout.main` / `mainChat`）；模块间距：**12px**。
- 顶栏高度：**56px**（`TopBar`）；底部导航：**64px**（`BottomNav`，含 safe-area）。

### 1.3 圆角尺度

与 `ThemeProvider`（Ant `borderRadius: 10`）及业务 CSS 对齐，新模块按层级选用：

| 层级 | 圆角 | 典型场景 |
|------|------|----------|
| **面板** | **8px** | 看板列、聊天气泡、甘特容器、文件列表/预览、驾驶舱卡片 |
| **控件** | **10px** | Ant 按钮/输入、`RegionButton` icon/pill、聊天侧栏抽屉按钮 |
| **模态 / 强调** | **12–14px** | Setup 内分组（12px）、Setup 外层 sheet（14px）、网络状态点（50% 圆） |

> 辅助值：2px 滚动条/指示条、4px @提及、6px `ViewSegment` 内 tab — 见 [视觉.md](../视觉.md) §5。

### 1.4 页标题语义

| 页面 | 标题文案 | 组件 |
|------|----------|------|
| 聊天 | 当前群名 / DM 对方名 | `ViewHeader` |
| 看板 / 任务树 / 甘特 / 文件 | 模块名（看板、任务树…） | `ViewHeader` |
| 驾驶舱 | 「驾驶舱」 | `ViewHeader` |

群组内与驾驶舱统一使用 Ant Design `Title level={4}`。

### 1.5 设计令牌（`global.module.css`）

| 变量 | 用途 |
|------|------|
| `--lanpm-accent` / `--lanpm-accent-hover` | 主强调色（亮 `#0071e3` / 暗 `#0a84ff`） |
| `--lanpm-accent-fill` / `--lanpm-accent-fill-strong` | 选中底、提及背景 |
| `--lanpm-accent-ring` | 拖放高亮外圈 |
| `--lanpm-border` | 面板/列表边框 |
| `--lanpm-bubble-bg` / `--lanpm-code-bg` | 聊天气泡、代码块底 |
| `--lanpm-separator` | Ant `colorBorder` 与细分隔线 |
| `--lanpm-success` / `--lanpm-warning` / `--lanpm-danger` | 网络状态、错误/拖放校验（亮暗各一套） |
| `--lanpm-shadow-sm` / `--lanpm-shadow-md` / `--lanpm-shadow-lg` | 浮层 elevation |

业务模块禁止硬编码 `#1677ff`；工具栏/空状态使用 `ui/ViewToolbar`、`ui/ViewState`。

### 1.6 交互区域（hover / active / selected）

| 场景 | 组件 | 约定 |
|------|------|------|
| 底部 5 Tab | `BottomNav` | 均分槽位；hover `--lanpm-hover-bg`；按下 `--lanpm-accent-fill-strong`；选中 `--lanpm-accent-fill` + 顶条 2px |
| 聊天 DM 会话 | `RegionTabBar` | 横向滚动 Tab；token 与 BottomNav 一致 |
| 成员列表行 | `MemberList` | 整行 hover/active；`dmBtn` 独立圆角区域 |
| 顶栏按钮 | `RegionButton` | `icon` / `pill` / `text` / `user` |
| 视图内切换 | `ViewSegment` | 文件分类、甘特日/周/月 |

- **disabled**：`opacity: 0.32` + `cursor: not-allowed`。
- 共享样式：`ui/regionInteract.module.css`；新 Tab 条优先复用 `RegionTabBar` / `ViewSegment`。

### 1.7 亮暗手验（发布前）

在亮/暗主题下逐页确认：聊天、看板、任务树、甘特、文件、驾驶舱、首次配置 — 边框、强调色、选中态、空状态文案可读。自动化：`npm run verify:visual`；人工步骤见 [05_测试与联调发布.md](./05_测试与联调发布.md) §2。

### 1.8 窄窗口断点（UX-R-01）

> 最小窗口 1280×720；以下断点为 **RC 已落地**（`UX-R-02~06`），窄于断点时按表降级。

| 断点 | 组件 | 行为 |

| `≤1100px` | `TopBar` | 工具区 flex-wrap；次要按钮收入折叠 |

## 2. 导航与路由

| 底部 Tab | 路由 | 说明 |
|----------|------|------|
| 聊天 | `/g/:groupId/chat` | 默认进入页 |
| 看板 | `/g/:groupId/board` | 仅项目群组可用 |
| 任务树 | `/g/:groupId/tree` | 仅项目群组 |
| 甘特图 | `/g/:groupId/gantt` | 仅项目群组 |
| 文件 | `/g/:groupId/files` | 项目群组；职能群可用 |

- 职能群组：隐藏看板/树/甘特 Tab 或置灰并提示「仅项目群组支持」。
- 匿名群组：仅保留聊天 Tab。

### Hash 路由与深链（`UX-V-08`）

Electron 渲染进程使用 **HashRouter**（URL 形如 `file:///…/index.html#/g/:groupId/chat`）。

| 场景 | 说明 |
|------|------|
| 应用内导航 | `navigate()` / `<Link>` 正常，无需额外处理 |
| 外部深链 | 可将完整 `index.html#…` 路径作为启动参数；首屏由 React Router 解析 hash |
| 刷新 / 重启 | hash 保留当前群与视图，适合桌面端单页应用 |
| 限制 | 无服务端 SSR；分享链接需包含 `#` 段；搜索引擎不索引 |

## 5. 状态与反馈

| 场景 | UI 反馈 |
|------|---------|
| 发送消息中 | 消息旁 ⏳ |
| 已发送 / 已读 | ✅ / ✅✅（按 `userId` 聚合） |
| 成员在线 | 🟢 在线 / 🟡 离开 / ⚪ 离线 |
| 网络断开 | 顶部条「连接中断，正在重试…」 |
| 加载中 | 骨架屏或 Spinner，≤300ms 不显示 |
| 错误 | Toast 3s 自动消失 + 可点击查看详情 |

## 6. 关键模块 UI 要点

### 6.0 任务多视图：内容统一、交互分视图

**原则**：看板 / 任务树 / 甘特图**不必**交互一致（单击、双击、拖拽可以不同），但**内容必须统一**——同一条 `Task` 记录、同一套 `taskStore` + `task:*` IPC；任一视图保存后，其它视图刷新即看到相同字段值。

| 约定 | 说明 |
|------|------|
| 数据模型 | 以 `docs/04` 任务实体为准；禁止某视图单独维护「另一份任务表」 |
| 编辑契约 | 完整字段保存走 `TaskDetailSaveInput`（`TaskDetailPanel` / `TaskEditModal` 共用） |
| 展示范围 | 可看板只列**根任务**、树列**层级**、甘特列**排期**——范围不同，底层仍是同一批 `taskId` |
| 视图重点 | 各视图只**突出**本场景字段；未在当页展示的字段仍存在于数据中，并可在跳转后的编辑入口修改 |

| 视图 | 交互重点（示例） | 内容重点（展示/编辑） |
|------|------------------|------------------------|
| 看板 | 拖列改状态、双击弹窗 | 状态列、优先级、负责人、截止、进度摘要 |
| 任务树 | 选中侧栏、行内改进度 | 父子结构、完整详情、子任务 |
| 甘特 | 拖条改期、单击改日期、双击里程碑 | 起止时间、依赖、里程碑 |

甘特图日期弹窗仅编辑起止日期属**交互裁剪**；完整字段请在看板（双击卡片）或任务树（右侧详情）修改，或通过甘特弹窗内「在看板中打开」跳转。

### 6.1 聊天

- 左栏成员列表宽度：240px，可折叠。
- 输入框支持：附件、代码块、`/task` 提示。
- 代码块：等宽字体，最大高度 360px，可展开。
- **`/task`（M3）**：`parseTaskCommand`；无标题时打开 `TaskCreateModal`；有标题时 `createFromChat` 并插入 `task_ref` 气泡（点击跳转看板）。仅项目群显示「任务」按钮（`taskAllowed`）。

### 6.2 看板

- 四列等宽滚动；列最小宽度 280px（`board.module.css`）。
- 拖放：`@dnd-kit/core`；整卡半透明（`opacity: 0.5`）；`DragOverlay` 浮层标题。
- 拖入 OTHER：`OtherReasonModal` 必填原因（与 `validateOtherReason` 一致）。
- 组件：`BoardView`、`KanbanCard`、`TaskEditModal`；路由 `/g/:groupId/board`；仅展示**根任务**卡片；双击卡片打开与任务树一致的详情字段（见 §6.0）。
- 实现细节：[05_测试与联调发布.md](./05_测试与联调发布.md) §7。

### 6.3 任务树 / 甘特图

- 树：Ant Design `Tree`（`TaskTreeView`）；父任务行内 `Progress` 百分比（聚合值，见 04 §3.4）；支持展开/折叠、根/子任务创建、叶子进度编辑。
- 路由 `/g/:groupId/tree`；与看板共用 `taskStore` / `task:*` IPC。
- 甘特：**M4** 基于 **`gantt-task-react`** 封装；日/周/月切换在工具栏；依赖线颜色 `#6b7280`；排期字段与 `docs/03` 同源；`locale` 跟随应用语言（见 [05](./05_测试与联调发布.md) §7）。

### 6.4 文件

- 左栏分类筛选；右栏列表 + 预览区（分栏或抽屉）。
- Office：预览区显示「本地转换中…」；失败提示下载。

## 8. 技术实现建议（已拍板）

| 项 | 选型 | 说明 |
|----|------|------|
| UI 库 | **Ant Design 5.x** | 主框架、表单、表格、树、看板布局 |
| 样式 | **CSS Modules** | 与 Ant Design `ConfigProvider` 主题配合；不引入 Tailwind |
| 状态 | **Zustand** | 群组/视图/会话等跨模块状态 |
| 甘特图 | **`gantt-task-react`** | M4 集成；支持拖拽与 FS/SS/FF/SF 依赖 |
| 图标 | **@ant-design/icons** | 统一图标源，禁止混用多套图标库 |
| 看板拖拽 | **`@dnd-kit/core`** + `@dnd-kit/utilities` | M3 看板跨列拖放；见 [05](./05_测试与联调发布.md) §7 |
| 任务状态 | **Zustand** `taskStore` | 按 `groupId` 缓存；订阅 `task:changed` 刷新 |

> 技术栈总览见 [02_技术实现建议](./02_技术实现建议.md) §18.2、[01_产品需求文档](./01_产品需求文档.md) §1.3。
