> 面向 M1 主框架与后续模块 UI 实现。索引见 [00_文档导航.md](./00_文档导航.md)。

## 1. 布局骨架

```
┌─ 顶部栏 56px ─────────────────────────────────────────┐
├─ 主内容区（flex:1，各视图路由）───────────────────────┤
└─ 底部导航 ~49px + safe-area（5 Tab，iOS 风格）────────┘
```

- 最小窗口：1280×720；推荐：1440×900。
- 主内容区内边距：**16px**（`MainLayout.main` / `mainChat`）；模块间距：**12px**。
- 顶栏高度：**56px**（`TopBar`）；底部导航：**49px** 内容区 + safe-area（`BottomNav`）。
- **顶底职责**：**顶栏** = 跨群切换、全局操作（发现/创建/搜索/网络）、偏好（主题/语言在用户菜单）；**底栏** = 当前群内五视图切换（聊天/看板/树/甘特/文件），不在顶栏重复 Tab。
- **顶栏降噪**：主题/语言在用户菜单；驾驶舱入口在「更多」（宽屏仅驾驶舱，窄屏与发现/创建/解散同菜单）；驾驶舱路由时 Logo 文案与 Tooltip 为「返回 {群名}」，与页内返回按钮一致。

### 1.3 圆角尺度

与 `ThemeProvider`（Ant `borderRadius: 10`）及业务 CSS 对齐，新模块按层级选用：

| 层级 | 圆角 | 典型场景 |
|------|------|----------|
| **面板** | **8px** | 看板列、聊天气泡、甘特容器、文件列表/预览、驾驶舱卡片 |
| **控件** | **10px** | Ant 按钮/输入、`RegionButton` icon/pill、聊天侧栏抽屉按钮 |
| **模态 / 强调** | **12–14px** | Setup 内分组（12px）、Setup 外层 sheet（14px）、网络状态点（50% 圆） |

> 辅助值：2px 滚动条/指示条、4px @提及、6px `ViewSegment` 内 tab。

### 1.4 页标题语义

| 页面 | 标题文案 | 组件 |
|------|----------|------|
| 聊天 | 当前群名 / DM 对方名 | `ViewHeader` + `showDivider` 发丝底边 |
| 看板 / 任务树 / 甘特 / 文件 | 模块名（看板、任务树…） | `ViewHeader`（大标题，无底部分隔） |
| 驾驶舱 | 「驾驶舱」 | `ViewHeader` |

群组内与驾驶舱统一使用 Ant Design `Title level={4}`。

### 1.5.1 字体族（`--lanpm-font-family`）

| 平台 | 实际字体 | 说明 |
|------|----------|------|
| **macOS** | San Francisco（`-apple-system`）+ 苹方（`PingFang SC`） | 即 Apple 系统 UI 字体，**无需**在工程内放 `.otf` |
| **Windows** | Segoe UI + 微软雅黑 | 系统自带 |

| 场景 | 组件 | 约定 |

## 2. 导航与路由

| 底部 Tab | 路由 | 说明 |
|----------|------|------|
| 聊天 | `/g/:groupId/chat` | 默认进入页 |
| 看板 | `/g/:groupId/board` | 仅项目群组可用 |
| 任务树 | `/g/:groupId/tree` | 仅项目群组 |
| 甘特图 | `/g/:groupId/gantt` | 仅项目群组 |
| 文件 | `/g/:groupId/files` | 项目群组；职能群可用 |

- 职能群组：看板/树/甘特 Tab **置灰 + 锁图标 + Tooltip**；聊天页顶部 **可关闭说明横幅**（`FUNCTION_GUIDE_STORAGE_KEY`）；点击禁用 Tab 仍可弹出说明。
- 匿名群组：BottomNav **仅渲染聊天 Tab**（不展示禁用占位）。
- 主视图切换：**仅 BottomNav**（不在任务页工具栏重复五 Tab）；跨视图捷径用 **`ViewCrossLink`**（看板↔树、甘特→看板等 pill）。
- 窄屏（`≤1100px`）：TopBar 发现/创建/解散收入 **更多** 菜单；全局搜索改为 **图标 + Popover**；驾驶舱亦在 **更多**（宽屏时「更多」仅含驾驶舱）。
- 全局搜索：结果副标题含 **目标视图**（`search.openInView`）。
- 聊天上下文栏（项目群）：**看板**、**群文件** 快捷入口。

### Hash 路由与深链（`UX-V-08`）

Electron 渲染进程使用 **HashRouter**（URL 形如 `file:///…/index.html#/g/:groupId/chat`）。

| 场景 | 说明 |
|------|------|
| 应用内导航 | `navigate()` / `<Link>` 正常，无需额外处理 |
| 外部深链 | 可将完整 `index.html#…` 路径作为启动参数；首屏由 React Router 解析 hash |
| 刷新 / 重启 | hash 保留当前群与视图，适合桌面端单页应用 |
| 限制 | 无服务端 SSR；分享链接需包含 `#` 段；搜索引擎不索引 |

## 6. 关键模块 UI 要点

### 6.0 任务多视图：内容统一、交互分视图

**原则**：看板 / 任务树 / 甘特图**不必**交互一致（单击、双击、拖拽可以不同），但**内容必须统一**——同一条 `Task` 记录、同一套 `taskStore` + `task:*` IPC；任一视图保存后，其它视图刷新即看到相同字段值。

| 约定 | 说明 |
|------|------|
| 数据模型 | 以 `docs/04` 任务实体为准；禁止某视图单独维护「另一份任务表」 |
| 编辑契约 | 完整字段保存走 `TaskDetailSaveInput`（`TaskDetailPanel` / `TaskEditModal` 共用） |
| 展示范围 | 看板**平铺全部任务** + **关系可视化**（族色条/标签/悬停高亮）；树列**层级**；甘特列**排期与依赖连线**——呈现不同，底层仍是同一批 `taskId` |
| 视图重点 | 各视图只**突出**本场景字段；未在当页展示的字段仍存在于数据中，并可在跳转后的编辑入口修改 |

| 视图 | 交互重点（示例） | 内容重点（展示/编辑） |
|------|------------------|------------------------|
| 看板 | 拖列改状态、悬停高亮关联、FS 前置拦截 | 状态列、父子/同级/依赖标签、**族色条**（`taskFamily.module.css`） |
| 任务树 | 选中侧栏、行内改进度、详情**前置/后继** | 父子结构、**同色条**、跳转看板/甘特定位 |
| 甘特 | 拖条改期、单击改日期、双击里程碑 | 起止时间、依赖、里程碑、**关联任务条同色** |

**工期健康度（三视图统一，不落库）**

| 项 | 约定 |
|----|------|
| 计算 | `shared/task/scheduleHealth.ts`：`getTaskScheduleHealth`、`getExpectedProgressPercent`；UI 类名与色值见 `scheduleHealthUi.ts` / `scheduleHealth.module.css` |
| 语义 | **绿** `on_track`：有排期且 `progressPercent` ≥ 期望进度；**深黄** `behind`：低于期望；**纯红** `overdue`：已过 `endDate`（延期优先）；`none`：无排期/未开始/已完成，不着色 |
| 排期输入 | 优先 `startDate`+`endDate`；仅 `endDate` 按单日；仅 `startDate` 默认 +7 天；无日期不标色 |
| 看板 | 整卡底纹 + 截止/进度字色（最强） |
| 任务树 | 行内左缘色条 + 进度条色；详情 `Alert` 展示期望/当前 % |
| 甘特 | 条样式：`scheduleHealth.ts` 内 `mergeGanttBarStyles` 合并族色（延期红条、落后黄/正常绿进度） |
| 驾驶舱 | `delayedCount` = 延期任务数；项目 `risk` = 存在落后任务（与看板同源规则） |

甘特图日期弹窗仅编辑起止日期属**交互裁剪**；完整字段请在看板（双击卡片）或任务树（右侧详情）修改，或通过甘特弹窗内「在看板中打开」跳转。

### 6.1 聊天

- 左栏成员列表宽度：240px，可折叠。
- **层次（亮/暗）**：成员侧栏、群聊/私聊模式条、上下文栏、输入区铺底 `--lanpm-surface-solid`；消息区保持 `--lanpm-bg` 作沟底，分界用 `--lanpm-border`（亮色约 18% 透明度，见 `global.module.css`）。
- 任务类视图标题：`ViewHeader` 底部分隔线（与看板/树/甘特/文件一致）。
- 输入框支持：附件、代码块、`/task` 提示。
- 代码块：等宽字体，最大高度 360px，可展开。
- **`/task`（M3）**：`parseTaskCommand`；无标题时打开 `TaskCreateModal`；有标题时 `createFromChat` 并插入 `task_ref` 气泡（点击跳转看板）。仅项目群显示「任务」按钮（`taskAllowed`）。

### 6.2 看板

- 四列等宽滚动；列最小宽度 280px（`board.module.css`）。
- 拖放：`@dnd-kit/core`；整卡半透明（`opacity: 0.5`）；`DragOverlay` 浮层标题。
- 拖入 OTHER：`OtherReasonModal` 必填原因（与 `validateOtherReason` 一致）。
- **删除**：拖至看板底部**垃圾桶区**（`board.trashDrop`）或任务树/卡片内删除操作；与 [01](./01_产品需求文档.md) §7.3「右键或拖至垃圾桶」一致。
- 组件：`BoardView`、`KanbanCard`、`BoardDependencyLines`、`TaskEditModal`；路由 `/g/:groupId/board`；**全部任务**平铺；**关系**：左侧色条（同族/同根）、卡片标签（父/子/同级、FS 等待、后继）、悬停或菜单「固定高亮」关联卡；**FS 依赖连线**（SVG 叠加层，与甘特同源）：默认仅**悬停/固定高亮**时绘制（黄=前置、强调色=后继）；工具栏 **「显示全部 FS 连线」** 开关（默认关，`localStorage` 记忆）开启后绘制全板浅灰 FS 边，焦点相关边仍加强；逻辑见 `shared/task/boardRelations.ts`（`listFocusDependencyEdges` · `listAllDependencyEdges`）。
- 实现细节：[05_测试与联调发布.md](./05_测试与联调发布.md) §7。

### 6.3 任务树 / 甘特图

- 树：Ant Design `Tree`（`TaskTreeView`）；父任务行内 `Progress` 百分比（聚合值，见 04 §3.4）；支持展开/折叠、根/子任务创建、叶子进度编辑。
- 路由 `/g/:groupId/tree`；与看板共用 `taskStore` / `task:*` IPC。
- 甘特：**M4** 基于 **`gantt-task-react`** 封装；日/周/月切换在工具栏；依赖线颜色 `#6b7280`；排期字段与 `docs/03` 同源；`locale` 跟随应用语言（见 [05](./05_测试与联调发布.md) §7）。

### 6.4 文件

- **布局**：顶栏分类筛选（`ViewToolbar` start）+ 主操作（end）；其下搜索行；再下为**传输面板**（限速 + 队列/历史）；主体宽屏为左列表 + 右预览；**≤960** 仅列表，选中后底部 Drawer 展示同一预览树（关闭 Drawer 不强制清选中）。
- **工具栏层级**：
  - 主 CTA：**上传**（`type="primary"`）
  - 次要：添加书签
  - 折叠：「更多」下拉 — 书签导入 / 导出（不与上传抢同一视觉权重）
  - **限速不在顶栏**，放在传输面板顶部（与队列/历史同区）
- **空态**：无内容 / 搜索无结果 / 分类无匹配 — 文案区分，并提供「上传」「添加书签」引导按钮
- **书签预览主次**：标题 → 可复制 URL → 主按钮「系统浏览器打开」→ 次「发到群聊」→ 内嵌 WebView 降级为参考预览（附提示文案，高度受限）
- **列表行级区分（「全部」混排）**：书签行名称旁链接图标 +「书签」Tag + 浅底 `rowBookmark`；类型列短文案「链接」；预览列书签显示「—」（不堆「链接」噪音）；操作列书签仅外开图标。**不分表 / 不双 Tab**
- Office：预览区显示「本地转换中…」；失败提示下载。

| 看板拖拽 | **`@dnd-kit/core`** + `@dnd-kit/utilities` | M3 看板跨列拖放；见 [05](./05_测试与联调发布.md) §7 |
| 任务状态 | **Zustand** `taskStore` | 按 `groupId` 缓存；订阅 `task:changed` 刷新 |
