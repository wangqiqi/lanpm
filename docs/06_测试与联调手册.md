## 1. NetworkStub 联调（M2，单机双实例）

### 1.1 环境

- 同一台开发机启动两个 LanPM 实例（不同 `--user-data-dir`）。
- 网络实现：`NetworkStub`（见 `docs/04` §6.4），本机共享总线目录 `$TMP/lanpm-stub`（`peers/*.json` + `bus.jsonl`）。

**自动化冒烟（单进程双 Stub）**

```bash
npm run verify:network-stub   # publish/subscribe/discoverPeers + 去重
npm run verify:m0             # storage + suffix + network-stub
```

**双 Electron 实例（M0-09 手验）**

```bash
# 终端 A
npm run dev -- --user-data-dir=/tmp/lanpm-a

# 终端 B
npm run dev -- --user-data-dir=/tmp/lanpm-b
```

两实例完成首次配置后，可在 `$TMP/lanpm-stub/peers/` 看到各自的 `dev_*.json`；后续 M2 将在此总线上收发 `SyncEnvelope`。

### 1.2 步骤

| # | 操作 | 预期 |
|---|------|------|
| 1 | 实例 A/B 完成首次配置，加入同一测试群组 | 成员列表互相可见 |
| 2 | A 发送文本消息 | B 实时收到，A 显示已发送 ✅ |
| 3 | B 打开会话（焦点在聊天区） | A 显示已读 ✅✅ |
| 4 | A 发送代码块 | B 语法高亮正确 |
| 5 | A `@B` | B 收到桌面通知 |
| 6 | A 输入 `/task 测试任务` | 聊天出现 `task_ref`；看板 TODO 列有新卡片 |

### 1.3 通过标准

- 上述步骤无报错；消息 `msgId` 不重复；已读按 `userId` 聚合。

## 2. 看板与任务树（M3，单机手验）

> 实现说明：[07_M3_看板与任务树实现说明.md](./07_M3_看板与任务树实现说明.md)

**自动化**

```bash
npm run verify:m3
npm run typecheck
```

**环境**：完成首次配置；群组选「示例项目」`demo-project`（职能群/匿名群应无法进入看板 Tab）。

| # | 操作 | 预期 |
|---|------|------|
| 1 | 聊天输入 `/task 联调任务A` | 成功 Toast；气泡「📋 任务：…」；点击跳转看板 |
| 2 | 看板 TODO 列见卡片；拖至 IN PROGRESS | 列变化持久；刷新仍在 |
| 3 | 拖至 OTHER，不填原因点确认 | 校验失败，无法移入 |
| 4 | 填原因「依赖阻塞」确认 | 卡片在 OTHER 列且展示原因 |
| 5 | 切任务树 Tab，建根任务 B、子任务 C | 树可展开；父节点进度为子任务均值 |
| 6 | 选中叶子 C，改进度 80% 保存 | 父 B 进度更新；看板若 B 为根任务则卡片显示 80% |

### 2.1 通过标准

- `verify:m3` 退出码 0；上表无阻塞缺陷。
- 匿名群 `demo-anonymous` 手动访问 `#/g/demo-anonymous/board` 应重定向到 `chat`。

## 3. 性能测量（M7）

### 3.1 冷启动 ≤ 3s

- **定义**：从双击图标到主界面可交互（底部 Tab 可点）。
- **环境**：关闭其它重型应用；SSD；各平台测 3 次取中位数。
- **记录**：`08` §16.11 性能表或联调记录附表。

### 3.2 内存

| 场景 | 操作 | 指标 |
|------|------|------|
| 空闲 | 启动后静置 60s | ≤ 200MB |
| 聊天活跃 | 连续收发 100 条消息 | ≤ 350MB |

- 工具：系统任务管理器 / `ps` / Electron DevTools Memory。

### 3.3 UI 响应 ≤ 100ms（P95）

- 操作：切换 5 个底部 Tab、发送一条消息。
- 各操作测 10 次，取 P95 ≤ 100ms（开发模式可放宽至 150ms 并注明）。

## 4. 局域网真网联调（M6）

### 4.1 环境

- 至少 2 台机器同一网段（或 VPN 互通）。
- 防火墙放行 UDP `43123` 与 WebRTC 所需端口（见 `docs/02` §13.5）。

### 4.2 步骤

| # | 操作 | 预期 |
|---|------|------|
| 1 | 启动实例，等待 3–15s | UDP 发现对端，成员列表出现 |
| 2 | A 发消息 | B 加密通道收到，抓包无明文正文 |
| 3 | A 上传 10MB 文件 | B 可下载，SHA256 一致 |
| 4 | 同用户双设备登录 | 列表显示一个用户，在线态合并 |
| 5 | 断开 A 网络 20s 再恢复 | 自动重连，离线消息补同步 |

### 4.3 通过标准

- 满足 `docs/03` §16.10 全部条目。
