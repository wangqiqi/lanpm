# 10_测试体系说明

> 与 `docs/06` 手验/联调互补：本节定义**自动化测试分层**与命令入口。索引见 [00_文档导航](./00_文档导航.md)。

## 1. 分层

| 层级 | 目录 / 命令 | 范围 | 依赖 |
|------|-------------|------|------|
| **单元** | `tests/unit/` · `npm run test` | `src/shared` 纯函数、协议常量 | Vitest，无 Electron/SQLite |
| **集成** | `scripts/verify-*.ts` · `npm run verify:m2` 等 | 主进程 + Stub + SQLite 冒烟 | Electron Node / better-sqlite3 |
| **全量回归** | `npm run verify:m7` | typecheck + test + visual + M0–M7 串联 | 见 `docs/08` |
| **手验** | `docs/06` · `docs/09` | 双机真网、三平台、亮/暗截图 | 人工 |

```
        ┌─────────────┐
        │  手验 docs/06/09  │
        └──────▲──────┘
               │
        ┌──────┴──────┐
        │ verify:m7   │  全量回归
        └──────▲──────┘
               │
     ┌─────────┴─────────┐
     │ verify:* 集成脚本   │
     └─────────▲─────────┘
               │
        ┌──────┴──────┐
        │ npm run test │  Vitest 单元
        └─────────────┘
```

## 2. 单元测试（Vitest）

### 2.1 命令

```bash
npm run test          # 跑 tests/unit，单次
npm run test:watch    # 监听模式（开发）
npm run test:coverage # 覆盖率（仅 src/shared）
```

### 2.2 约定

- 文件命名：`tests/unit/<域>/<模块>.test.ts`
- 只测**无 IO、无 Electron** 的逻辑；需要 DB/网络的用 `scripts/verify-*`
- 新增 shared 纯函数时**优先**补单元测试，再视需要加 verify 冒烟

### 2.3 当前覆盖域

| 域 | 用例文件 | 对应 shared |
|----|----------|-------------|
| chat | `mentions.test.ts` | `@shared/chat/mentions` |
| chat | `taskCommand.test.ts` | `@shared/chat/taskCommand` |
| chat | `offlineSync.test.ts` | `@shared/chat/offlineSync` |
| navigation | `tabRules.test.ts` | `@shared/navigation/tabRules` |
| file | `previewExtensions.test.ts` | `@shared/file/previewExtensions` |
| file | `sync.test.ts` | `@shared/file/sync` |
| task | `progress.test.ts` | `@shared/task/progress` |

## 3. 集成脚本（verify:*）

保留现有 `scripts/verify-*.ts` 作为集成层，**不迁移**到 Vitest（避免 Electron ABI / SQLite 与 Vitest 环境耦合）。

| 脚本 | 说明 |
|------|------|
| `verify:m7` | 发布前全量门禁（含 `npm run test`） |
| `verify:task-sync` / `verify:file-sync` | P2P 同步双 Stub |
| `verify:m2-integration` | 聊天 + 已读 + 任务 |
| 其余 `verify:m0`–`m6` | 各里程碑冒烟 |
