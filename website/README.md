# LanPM website

VitePress project homepage. Deployed to GitHub Pages at [wangqiqi.github.io/lanpm](https://wangqiqi.github.io/lanpm/).

## Local development

```bash
npm run docs:dev      # http://localhost:5173/lanpm/
npm run docs:build
npm run docs:preview  # preview production build
```

Static assets under `public/` are generated by `npm run website:prepare` (copies `assets/` and `resources/logo.svg`).

Engineering SSOT remains in repo [docs/](https://github.com/wangqiqi/lanpm/tree/master/docs) — the site links there instead of duplicating long-form specs.
