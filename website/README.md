# LanPM website

VitePress project homepage. Deployed to GitHub Pages at [wangqiqi.github.io/lanpm](https://wangqiqi.github.io/lanpm/) (**Chinese by default**; English at `/en/`).

## Local development

```bash
npm run docs:dev      # http://localhost:5173/lanpm/
npm run docs:build
npm run docs:preview  # preview production build
```

Static assets under `public/` are generated by `npm run website:prepare` (copies `assets/` and `resources/logo.svg`).

Published pages under `website/` (except this README) must be **self-contained**: no links into unpublished engineering specs. `verify:docs-links` enforces that.
