# 暗色主题截图基线（手工对照）

由无头 Electron 自动生成，**非**设计稿定稿。

## 生成命令

```bash
npm run build && npm run verify:visual-screenshots
```

默认输出目录：`.lanpm/visual-screenshots/`（gitignore）。本目录从该目录复制 `dark_*.png`（七页主视图，不含 `setup`）。

| 文件 | 视图 |
|------|------|
| `dark_chat.png` | 聊聊 |
| `dark_board.png` | 看板 |
| `dark_tree.png` | 任务树 |
| `dark_gantt.png` | 甘特图 |
| `dark_calendar.png` | 日历 |
| `dark_files.png` | 文件 |
| `dark_cockpit.png` | 驾驶舱 |
